## Usage

```tsx showLineNumbers
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select"
```

```tsx showLineNumbers
const items = [
  { label: "Light", value: "light" },
  { label: "Dark", value: "dark" },
  { label: "System", value: "system" },
]

<Select items={items}>
  <SelectTrigger className="w-[180px]">
    <SelectValue placeholder="Theme" />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      {items.map((item) => (
        <SelectItem key={item.value} value={item.value}>
          {item.label}
        </SelectItem>
      ))}
    </SelectGroup>
  </SelectContent>
</Select>
```

## Composition

Use the following composition to build a `Select`:

```text
Select
├── SelectTrigger
│   └── SelectValue
└── SelectContent
    ├── SelectGroup
    │   ├── SelectLabel
    │   ├── SelectItem
    │   └── SelectItem
    ├── SelectSeparator
    └── SelectGroup
        ├── SelectLabel
        ├── SelectItem
        └── SelectItem
```

## Align Item With Trigger

Use `alignItemWithTrigger` on `SelectContent` to control whether the selected item aligns with the trigger. When `true` (default), the popup positions so the selected item appears over the trigger. When `false`, the popup aligns to the trigger edge.

## Invalid

Add the `data-invalid` attribute to the `Field` component and the `aria-invalid` attribute to the `SelectTrigger` component to show an error state.

```tsx showLineNumbers /data-invalid/ /aria-invalid/
<Field data-invalid>
  <FieldLabel>Fruit</FieldLabel>
  <SelectTrigger aria-invalid>
    <SelectValue />
  </SelectTrigger>
</Field>
```

## Size

Set `size` once on `Select`. The trigger and the popup follow together, so item text stays on the trigger's text inset at every size. `SelectTrigger` still accepts its own `size` when a trigger has to differ.

<ComponentPreview name="select-size" />

## Variant

Set `variant` on `Select` and the trigger follows. `default` is the outlined field, `secondary` a gray fill that darkens on hover, and `ghost` is transparent with no hover, for a field on a toolbar or a surface of its own. They match the `outline`, `secondary` and `ghost` button. The popup is the same in every variant.

<ComponentPreview name="select-variants" />

## Rounded

Set `shape="rounded"` on `Select` for a pill trigger. Like `size` and `variant`, `SelectTrigger` accepts its own `shape` when one trigger has to differ.

<ComponentPreview name="select-rounded" />

## API Reference

### Select

| Prop      | Type                                  | Default     |
| --------- | ------------------------------------- | ----------- |
| `size`    | `"sm" \| "default" \| "lg"`           | `"default"` |
| `variant` | `"default" \| "secondary" \| "ghost"` | `"default"` |
| `shape`   | `"default" \| "rounded"`              | `"default"` |

`size`, `variant` and `shape` flow to `SelectTrigger`, which accepts each of them to override the root.

See the [Base UI Select](https://base-ui.com/react/components/select#api-reference) documentation for the rest.
