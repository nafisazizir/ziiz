ziiz carries two toasts. [Toast](/components/toast) is the Base UI one, driven by a
toast manager you call imperatively. Sonner is the third-party alternative:
it renders its own stack, follows the active theme through `next-themes`, and
takes a shorter call.

## Usage

Mount the `Toaster` once, near the root of the app.

```tsx
import { Toaster } from "@/components/ui/sonner"
```

```tsx
<Toaster />
```

Then call `toast` from anywhere.

```tsx
import { toast } from "sonner"

toast("Event created", {
  description: "Sunday, December 3 at 9:00 AM",
})
```
